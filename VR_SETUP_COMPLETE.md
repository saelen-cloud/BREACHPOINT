# BREAKPOINT VR Setup

This project is configured for Meta Quest (Android) and desktop OpenXR using Unity 6000.3.26f1, URP 17.3, XR Plug-in Management, and OpenXR 1.10.

All XR configuration and scene construction is generated by one Editor script:

- `Assets/Editor/VRSetup.cs`

Run it from **Tools > BREAKPOINT > Configure VR Project**, or in batch mode:

```powershell
& "C:\Program Files\Unity\Hub\Editor\6000.3.26f1\Editor\Unity.exe" `
  -batchmode -quit -projectPath . `
  -executeMethod VRSetup.RunBatch `
  -logFile Logs\vrsetup.log
```

Build an APK from **Tools > BREAKPOINT > Build Android APK**, or in batch mode:

```powershell
& "C:\Program Files\Unity\Hub\Editor\6000.3.26f1\Editor\Unity.exe" `
  -batchmode -quit -projectPath . `
  -executeMethod VRSetup.BuildAndroidBatch `
  -logFile Logs\androidbuild.log
```

The APK is written to `Builds/BREAKPOINT.apk`.

## XR Plug-in Management

Generated assets:

- `Assets/XR/XRGeneralSettingsPerBuildTarget.asset`
- `Assets/XR/Loaders/OpenXRLoader.asset`
- `Assets/XR/Settings/OpenXRPackageSettings.asset`

Configuration:

- **Standalone** and **Android** both use the OpenXR loader only.
- `InitManagerOnStart` is enabled for both build targets.
- No other loader (Mock, Simulation) is assigned.

## Scene

`Assets/Scenes/SampleScene.unity` contains:

- `XR Origin (XR Rig)` — the official XRI 3.0.1 Starter Assets prefab instance
  (head tracking, hand/controller tracking, locomotion, teleport and grab
  interactors already wired).
- `XR Interaction Manager`.
- `EventSystem` with `XRUIInputModule` (XR input and mouse input enabled).
- A 10 x 10 m floor with `TeleportationArea`.
- A table and three grabbable physics cubes with `XRGrabInteractable`.
- Directional light and trilight ambient lighting.

The scene is the only entry in **Build Profiles > Scene List**.

## Testing on a Quest

1. Enable **Developer Mode** on the headset in the Meta Horizon mobile app.
2. Connect the headset over USB and allow USB debugging.
3. Install the APK:

   ```powershell
   adb install -r Builds\BREAKPOINT.apk
   ```

4. Launch **BREAKPOINT** from **Unknown Sources** in the headset.

For desktop testing without a headset, install the XR Device Simulator sample
from the XR Interaction Toolkit package and enable it in the OpenXR feature
list.

## Notes

- The Meta XR All-in-One SDK (`com.meta.xr.sdk.all`) is **not** required for
  basic OpenXR Quest support. It is only needed for Meta-specific features
  such as hand tracking APIs, scene understanding, and Meta avatars.
- OpenXR settings live in `Assets/XR/Settings/OpenXRPackageSettings.asset` and
  are generated by Unity. Edit them through **Project Settings > XR Plug-in
  Management > OpenXR** rather than by hand.
- Do not add `m_StereoRenderingMode` to URP renderer assets. URP 17.3 controls
  stereo rendering through the OpenXR render mode setting.
